# Projet BankThread

## Choix de la technologie
Nous avons choisi le langage Python car c'est le langage qui a été utilisé pour la majeur partie du cours
et c'est également le langage avec nous nous sentions le plus à l'aise.

## Lancement du projet

Récupérer le projet via github
```
git clone https://github.com/Shad0wz93/MultiThreadPython.git
```

Créer un environnement virtuel dans un dossier .venv pour avoir un interpréteur local
```
python -m venv .venv
```

Lancer la simulation avec la commande
```
python main.py
```

## Liste des US implémentées

- US-01 : Compte bancaire thread-safe
- US-02 : File d'attente des clients
- US-03 : Guichets : pool de threads
- US-04 : Virement entre comptes sans deadlock
- US-05 : Tableau de bord temps réel
- US-06 : Alarme de découvert
- US-07 : Limite simultanée aux DAB
- US-08 : Historique concurrent des opérations
- US-09 : Simulation de charge (stress test)
